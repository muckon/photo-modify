# 红纸金漆婚礼请柬

把真实摄影、源自场景的大笔触、纸面留白和独立排版组合成请柬。已有照片、版式或 PPT 时，接续用户最后接受并保存的版本。红金是可选的完成路径，不能替代用户已确定的配色和修改范围。

本技能是参考 Gathered Scenes Zine 构图思路重新编写的扩展工作流，新增原片合成、可编辑 PPT、原位改色、材质填充与验证方法；并非上游原版。保留上游作者 Zeejay0 的署名和个人非商业许可，见 [来源说明](references/sources-and-license.md) 与 [LICENSE](LICENSE)。

## 接入与选择路径

- 先读项目 `AGENTS.md`；只检查用户指定的照片、当前选中照片或已知交付目录，避免扫描整个图库。
- 已有 PPT：查验页数、页面比例、图层、文字、字体和当前喜字颜色。保存时间只是线索，应以实际新增内容确认用户的保存版本；无法区分时询问源文件。
- 只有照片：读尺寸、方向和预览，构图与摄影分辨率分别规划。按需读取 [从照片建立拼贴](references/photo-collage.md)。
- 改文字、改色或换材质：直接编辑现有对象。按需读取 [PPT 原位编辑](references/pptx-editing.md)。
- 需要纸纹、金漆或金粉：读取 [材质提示词](references/material-prompts.md)。

调用宿主的 Presentations 技能处理 PPT；调用 imagegen 技能生成独立的纸面、笔触或材质。若环境没有这些技能，使用可用的同类能力，先检查实际支持的编辑与渲染方式，不编造工具名或安装路径。

## 摄影内容的边界

- 人脸、头发、表情、姿势和原始光学结构都从原片获得。禁止对婚纱照片进行生成式整图编辑、换脸、五官重塑、发型生成、AI 面部修复或 AI 磨皮。
- 把照片作为完整摄影图层，通过明确记录的缩放、平移、裁切及 Alpha 遮罩参与合成。材质生成只接收材质需求，不接收包含人物的整幅请柬。
- 只有收到光色修改要求后，才进行常规曝光、白平衡、曲线等非生成式调整；强度由源片决定。不得把示例中的曝光值套用为默认值。
- Lightroom 继续服从项目只读约定。确需显影时，先创建命名虚拟副本，记录并核对副本与原片关系，再只编辑副本；不自行改全局 MCP 配置。
- 若当前摄影来自小预览，用可获得的高清原片按已接受的遮罩重合成摄影区域。不要通过生成式补脸或锐化掩盖低分辨率。来源不足时说明成品分辨率的限制。

## 构图与可编辑结构

新稿通常适合竖向 3:5，但优先遵守来源方向、已有页面和用户尺寸。用一到两个来源于水线、山脊、道路或人物动作的主导轮廓组织拼贴。照片保留核心人物与空间关系；抽象笔触承担眼动，纸面承担文字与留白。撕纸纤维只沿主要交界展开，避免均匀白框、发光边和厚重投影。

至少区分纸面、插画笔触、摄影这三个独立图层。文字使用原生独立文本框；日期、姓名、场地等只采用用户提供内容，不自行补造。用户只要无文字稿时不添加文字。喜字优先复用用户提供的矢量轮廓或合法可用的字体，不让生图模型重写字形。

高清合成用目标画布和同一组几何变换。背景或插画放大不会新增真实细节；PPT 内嵌的摄影素材应保留可用原始分辨率，并关闭自动图片压缩。除非用户要求，不能把文字、喜字和照片整体压成一张背景。

## 从现有 PPT 迭代红金版本

1. 复制用户当前稿，保留所有页、文本、字体、字号、段落、位置、照片裁切及遮罩；只改变用户指定对象。
2. 红底可取当前喜字颜色作基准。示例朱红为 `#B61D32`，浅金文字为 `#E9CC8B`。实际配色服从当前稿，不能把这些值当成通用固定色。
3. 平涂红金版先检查层级和可读性。大喜字可用轻微金色渐变，小字保持稳定、清晰的浅金色。
4. 若用户要求纹理，在该版本上新增红色纤维纸纹和金漆金粉材质。喜字保留原矢量路径，用原生图片填充把金粉限制在字形内部；不要用栅格图片替换整枚喜字。
5. 检查换底色后显露的浅色底边。需要修正时，仅处理已识别的纸面或插画底色，保持原摄影及 Alpha 几何；没有把握时保留现状或提供局部预览，不按颜色阈值批量改婚纱、皮肤或头发。

普通编辑优先用可用演示文稿接口。若导入再导出会损伤原文件，使用 [PPT 编辑参考](references/pptx-editing.md) 中的定点 OOXML 方法；脚本只接受显式目标，不猜测对象。

## 交付前检查

- 在 PowerPoint 或可靠渲染器里逐页看全图，再看人物、撕纸边、喜字及最小文字；缩略图也应有清楚层级。
- 验证页数、所有文字与排版仍与源稿一致；纹理版的文字仍可编辑，喜字仍保有矢量轮廓。
- 未要求摄影光色变化时，摄影素材应保持字节一致。要求了显影时，改用几何、Alpha、调整记录和局部原片对照验证，不能声称像素完全未改。
- 检查真实素材尺寸，而非只看导出的 PNG 或 DPI 标记。高分辨率 PNG 如需交付，按页面比例导出；3:5 示例为 4800×8000，不强制用于所有稿件。
- 默认在用户项目的 `output/<任务名>/` 下用新文件名交付 PPT；按用户要求附高清 PNG。未要求打印定稿时不提前生成 PDF。
- 保留源片、已接受版本、源素材和许可。用简短说明区分屏幕上的金漆视觉效果与印厂的实体烫金工艺。

运行时产生的配置、预览、素材和交付记录保存在用户的任务目录，不能写入技能安装目录。技能不包含任何自动上传、发布、同步图库或连接第三方服务的步骤。将工作流另存为可分享技能时，只打包经核对的通用文件，继续保留作者和许可说明。
